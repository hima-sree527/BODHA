# Bodha (बोध) — Learn Through Your World
> **B2B Adaptive AI Tutor for Schools (KG to Class 12 / Ages 3–18)**

---

## 🌟 Overview

**Bodha** (from the Sanskrit root *बोध*, meaning genuine understanding/awakening, as opposed to rote memorization) is an adaptive 1-on-1 AI pedagogy platform built for schools. 

In a traditional classroom of 40–60 students, a single teacher cannot personalize pacing, analogies, or explanations for every child. Bodha translates core curriculum concepts into what each student already loves (Cricket, Space, Gaming, Animals, Music, Animation, and custom passions), matching their exact developmental stage from Early Childhood (Age 3) through Senior High School (Age 18).

---

## 🎯 Key Features

1. **Tagline & Hero Philosophy**: *"Learn Through Your World"* — personal relevance over generic worksheets.
2. **Interactive AI Tutor Simulator**:
   - **Age Slider (3–18)**: Dynamically switches cognitive scaffolding across 4 developmental bands (Early Years, Primary, Middle School, High School).
   - **6 Interest Presets + Custom Parser**: Cricket, Space, Gaming, Animals, Music, Movies + free-text support.
   - **Concept: Fractions**: Tailored with custom real-world vocabulary, dynamic SVG fraction visuals, and Socratic teach-backs.
   - **Zero Latency / Zero External APIs**: Pure local state simulation that cannot fail during live demos or presentations.
3. **Why It Matters (Classroom Reality)**:
   - The 1:50 Ratio Bottleneck
   - Silent Compounding Learning Gaps
   - Extrovert & Fluency Bias
   - Memorization vs. Understanding Trap
4. **How It Adapts (Institutional Pedagogy)**:
   - Low-stakes diagnostic → Real-time difficulty adjustment → "Explain why" Socratic check → Multilingual toggle preview (English, Hindi, Tamil, Telugu, Marathi) → Zero-shame psychological safety.
5. **Hackathon Judge Briefing**:
   - Technical distinction: Dynamic 1-on-1 cognitive scaffolding vs. static MCQ digital worksheets.
   - Closed-domain NCERT/CBSE alignment guardrails.
   - Ultra-lightweight low-bandwidth lab footprint.
6. **Built for Schools (B2B Admin & Contact Form)**:
   - Classroom Mastery Heatmaps, Safe Sandboxes, Distress & Anxiety detection alerts.
   - Interactive School Pilot request form with animated instant success state.

## 🚀 Running Locally

Because this project is self-contained in `index.html` with zero external build dependencies:

```bash
# Option 1: Using Python HTTP server
python -m http.server 3000

# Option 2: Using Node npx serve
npx serve .
```

Then open `http://localhost:3000` in your web browser.
